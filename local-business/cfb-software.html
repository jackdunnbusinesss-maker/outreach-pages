Embedded Oberon Development Tools

Professional tooling for Oberon-based embedded systems development

CFB Software builds development tools for engineers working with Oberon on ARM Cortex-M and RISC5 FPGA targets. Precise, lean, and built for real hardware.

CFB Software produces the Astrobe integrated development environment, purpose-built for writing, compiling, and deploying Oberon programs directly to embedded targets. The toolchain runs on Windows 10 and 11 (64-bit) and covers the RP2040, RP2350, ARM Cortex-M0 through M7, and RISC5 FPGA platforms.

Unlike general-purpose IDEs adapted for microcontrollers, Astrobe is designed from the ground up around the Oberon language and the constraints of bare-metal embedded programming. The result is a focused, fast workflow with no unnecessary abstraction between your code and the hardware it runs on.

The HCFiler library extends this with a lean SDHC filesystem implementation optimised for embedded systems, where code size and determinism matter more than feature breadth.

Tools and platforms

  • Astrobe for RP2040 / RP2350

    Full Oberon development environment targeting the Raspberry Pi RP2040 and RP2350 microcontrollers. Compile, link, and deploy to the target from a single Windows-based IDE.

  • Astrobe for ARM Cortex-M

    Supports Cortex-M0, M3, M4, and M7 cores. Write Oberon for industry-standard ARM targets without relying on a C toolchain or vendor SDK layer.

  • Astrobe for RISC5 FPGA

    Targets the RISC5 soft processor on FPGA hardware. A self-contained path from Oberon source to a running FPGA system.

  • HCFiler

    A lean SDHC filesystem library for embedded systems. Small footprint, straightforward API, designed for the resource constraints of microcontroller environments.
