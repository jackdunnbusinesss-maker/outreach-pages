About CFB Software

CFB Software makes Astrobe — a professional Oberon-based IDE and compiler purpose-built for embedded microcontroller development. Where most embedded toolchains are complex, fragile, and require deep configuration, Astrobe is designed to be clean, reliable, and productive from the start.

The Oberon language's strong type system and module structure make it exceptionally suited for safety-critical and resource-constrained embedded systems. Astrobe brings this power to ARM Cortex-M microcontrollers and Raspberry Pi RP2040/RP2350 boards, running on Windows 10/11 with a self-contained, zero-dependency toolchain.

CFB Software also produces HCFiler — a complete SDHC filesystem implementation for embedded systems — and Astrobe for RISC5 FPGA, extending Oberon development to hardware description targets.

CFB Software Products

  • Astrobe for RP2040 & RP2350

    Full Oberon IDE and compiler targeting the Raspberry Pi RP2040 and RP2350 microcontrollers — enabling professional embedded development on the Pi platform with native Oberon code.

  • Astrobe for Arm Cortex-M

    Oberon development tools for ARM Cortex-M0, M3, M4, and M7 microcontrollers — a complete IDE and compiler suite covering the most widely deployed embedded processor families.

  • Astrobe for RISC5 FPGA

    Oberon-based tooling targeting the RISC5 FPGA processor — enabling Oberon development on soft-core FPGA implementations of the RISC5 architecture.

  • HCFiler — SDHC Filesystem for Embedded Systems

    A complete, lightweight SDHC/SD card filesystem implementation designed for embedded Oberon systems — providing reliable file storage on microcontrollers without an OS dependency.
